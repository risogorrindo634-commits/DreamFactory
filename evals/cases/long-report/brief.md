# 任务：年度盘点

用一支 80 到 95 秒的中文数据短片，做某视频社区代码生成作品的 2026 年度盘点。

- 观众：要写年终总结的社区运营团队。
- 依次讲四件事，一件一个画面：
  1. 全年总量，以及它是 2025 年的多少倍。
  2. 按类型的分布，用柱状图。讲到最多的类型、它的数量和占比。
  3. 逐月走势，必须用折线图。讲到全年最高的月份和它的数量，这个数量要标在图上。
  4. 三种做法每分钟成片的成本区间，用对数刻度的区间图。讲到代码生成和外包制作各自的区间。
- 结尾提醒一次：这是虚构的示例数据。
- 数据都在 `data.json` 里，不要使用其中没有的数字。
